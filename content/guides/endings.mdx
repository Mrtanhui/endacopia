## Spoiler-free comparison

Endacopia's ending structure rewards both direct completion and deeper preparation. The three lettered endings are the main comparison players search for, while community guides also document an extra Yeti ending.

- **Ending A** — a standard route choice suited to a first completion.
- **Ending B** — an alternate main branch for seeing the other direct outcome.
- **Ending C** — a cross-area collectible and secret route for a planned completionist run.
- **Yeti ending** — an extra conditional route best explored after the main story.

This comparison is an orientation tool. The separate sections below contain the branch choices; leave those closed if you are still playing blind.

## Ending A and Ending B

The main A/B branch depends on which saw you hand over after Chapter II. Keep a separate save before that handover if you want to return to the choice. The [community ending guide](https://steamcommunity.com/sharedfiles/filedetails/?id=3773635669) documents both selections; the sections below reveal them separately.

If you have not reached the saw choice, use the [Saw box password guide](/puzzles/password) for the preceding computer and attic steps.

## Ending A: choice and completion

1. At the Chapter II epilogue, select the **Toy Saw**.
2. Give that saw to the bathroom monster, then continue through Chapter III.
3. In the final house sequence, take the marked forbidden-door route and accept Tip's help. Inspect the tooth-filled opening, return to the previous room and try the newly opened exit; this leads to Henry's fight.

The saw choice follows [Dolphin's ending guide](https://steamcommunity.com/sharedfiles/filedetails/?id=3773635669); the house continuation follows [xixi's Escape section](https://steamcommunity.com/sharedfiles/filedetails/?id=3774754099). Continue the final interactions through the credits and check for the **Escape** achievement. Receiving the saw alone is not the completion check.

## Ending B: choice and completion

1. Return to a save before the Chapter II handover.
2. Select the **real Saw** and give it to the bathroom monster.
3. Continue Chapter III and its epilogue to the end; check for the **Return** achievement.

This branch choice is documented by [Dolphin](https://steamcommunity.com/sharedfiles/filedetails/?id=3773635669). If you handed over the Toy Saw, return to the earlier save rather than looking for a later dialogue option to replace that choice. We have not tested every possible save state.

## Ending C

Ending C is a route, not a single button. Sources tie it to all 18 fish, the Old Key, Projector Room information, actions across Timesville, Misery Town, and the Office, the phone number `277-5944`, a waiting condition, and a later symbol puzzle.

Open the [full Ending C guide](/endings/ending-c) only when you are ready for exact steps. If a requirement is missing, do not assume the route can be repaired after passing a final transition.

## Extra Yeti ending

Neoseeker's ending overview documents a separate Yeti ending alongside the lettered routes. Treat it as an extra discovery rather than “Ending D” unless official naming confirms otherwise. That distinction keeps community shorthand from becoming false official terminology.

## Save advice

- Keep a clean save before a final branch or irreversible transition.
- Finish fish, secret-room, and optional-boss cleanup before attempting Ending C.
- Do not overwrite the only save that reaches a branch quickly.
- Recheck route conditions against a written guide if a video skips inventory screens.

If you intend to see A and B, preserve a save before the saw handover. If you are also preparing C, keep your earlier area-preparation save separately; do not assume a save made after a branch can recover unfinished area requirements.

> This guide names the community-documented routes but avoids inventing a canon or “best” ending. Interpretation belongs after you have seen the outcomes yourself.
