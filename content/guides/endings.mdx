## Spoiler-free comparison

Endacopia's ending structure rewards both direct completion and deeper preparation. The three lettered endings are the main comparison players search for, while community guides also document an extra Yeti ending.

- **Ending A** — a standard route choice suited to a first completion.
- **Ending B** — an alternate main branch for seeing the other direct outcome.
- **Ending C** — a cross-area collectible and secret route for a planned completionist run.
- **Yeti ending** — an extra conditional route best explored after the main story.

The table is an orientation tool, not a trigger list. If you are still playing blind, make a save before a clear final commitment and return after the credits.

## Ending A and Ending B

The direct endings sit closer to the main progression than Ending C. Their value on a first run is that they preserve surprise and reveal how the game's apparent objective connects to its larger themes.

Because exact branch wording can spoil late scenes, this overview does not reproduce dialogue choices out of context. Use the chapter walkthrough to reach the decision naturally, then make a separate save if the game state allows you to explore the alternate outcome.

## Ending C

Ending C is a route, not a single button. Sources tie it to all 18 fish, the Old Key, Projector Room information, actions across Timesville, Misery Town, and the Office, the phone number `277-5944`, a waiting condition, and a later symbol puzzle.

Open the [full Ending C guide](/endings/ending-c) only when you are ready for exact steps. If a requirement is missing, do not assume the route can be repaired after passing a final transition.

## Extra Yeti ending

Neoseeker's ending overview documents a separate Yeti ending alongside the lettered routes. Treat it as an extra discovery rather than “Ending D” unless official naming confirms otherwise. That distinction keeps community shorthand from becoming false official terminology.

## Save advice

- Keep a clean save before a final branch or irreversible transition.
- Finish fish, secret-room, and optional-boss cleanup before attempting Ending C.
- Do not overwrite the only save that reaches a branch quickly.
- Recheck route conditions against a written guide if a video skips inventory screens.
