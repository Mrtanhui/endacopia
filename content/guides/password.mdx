## The code

The verified code for the **Saw box** in the formal Steam release is:

> `471`

Use it at the Saw box in the attic trunk sequence. If you are looking at a different password screen, do not assume this number applies.

## Where 471 comes from

The game provides the answer through Henry's records rather than a brute-force pattern.

1. Complete the relevant Chapter 2 Henry sequence.
2. Recover **Henry's Floppy Disk**.
3. Use the disk at the appropriate computer.
4. Open Henry's profile.
5. Read the `Passwords` file.
6. Find the `Saw box` entry: `471`.

The file label and box label are important evidence that the number belongs to this scene.

## Where to enter it

Return to the attic trunk and interact with the Saw box. Enter `471` when its code input is active. If no input appears, confirm you have advanced the route to the correct trunk state rather than trying to type at a decorative object.

## Demo password warning

Search results include Endacopia demo password videos and discussions. The demo and formal release can expose different scenes, so a generic title such as “the Endacopia password” is ambiguous.

This guide deliberately names the **Saw box** in the title and answer. It does not claim that `471` opens every password interaction in every version.

## Troubleshooting

- Verify that the game is the formal Steam release and the object is the Saw box.
- Read Henry's Passwords file so the route state is complete.
- Enter only the three digits `471`.
- If a walkthrough shows another code, compare its version and room before replacing the answer.
