## Henry's role

The community character page describes Henry as a major antagonist connected to Mellow. His threat is reinforced through pursuit and through records that let the player investigate him indirectly.

This page keeps route facts separate from interpretation. The exact nature of Henry's relationship to the wider story is best experienced in the game; the practical guide focuses on the chase, Floppy Disk, computer, and code.

## Chapter 2 encounter

Neoseeker's Chapter 2 route places an important Henry sequence behind the mirror area. Follow the room's escape and pursuit logic, then search the resulting path carefully instead of rushing to the next objective.

The item you need for the later information step is **Henry's Floppy Disk**. It is not the final password itself; it unlocks the record that contains the password.

## Floppy Disk and computer profile

Take the disk to the appropriate computer and open Henry's profile. Inside, read the `Passwords` file. The formal Saw box entry is `471`.

The item chain matters because it tells you which code the number belongs to. Endacopia contains other password searches, especially around older demo material, so entering a number without its scene label creates confusion.

## Using code 471

The code belongs to the **Saw box** in the attic trunk sequence. Enter `471` there after you have reached the correct state. If the input does nothing, verify that you are at the formal-release Saw box rather than a different demo or environmental interaction.

Use the focused [password guide](/puzzles/password) when you need only the code and route. It intentionally labels the scene in the title and quick answer.

## Why Henry matters to the guide

Henry is a good example of Endacopia's layered clue design: a threatening encounter produces an ordinary-looking disk, the disk produces a private profile, and the profile resolves a physical lock elsewhere. Character knowledge and puzzle progression are not separate systems here.
